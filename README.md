# Go 圧力シミュレーター (WebUI)

Go言語で物理演算（圧力の拡散）を行い、ブラウザ（HTML5 Canvas + WebSocket）上でリアルタイムに可視化するインタラクティブなシミュレーターです。

二次元格子（グリッド）上での簡易的な拡散方程式をベースにしており、クリックやドラッグによってリアルタイムに圧力を注入・伝播させることができます。

## 特徴

- **高速な物理演算**: Go言語のGoroutineを活用し、バックグラウンドで高速にシミュレーションを更新。
- **リアルタイム通信**: WebSocket（双方向通信）により、サーバーサイドの計算結果をブラウザへ約30〜60FPSで滑らかに転送。
- **滑らかな可視化**: HSLカラーを用いたヒートマップ風のグラデーション描画。
- **インタラクティブ性**: マウスによるクリックやドラッグ操作で、自由な場所に新たな圧力（波）を生み出すことが可能。

## システム構成

[ Go サーバー (メインプロセス) ]│├── バックグラウンド物理演算 (Goroutine / 約60FPS)│└── [ WebSocket ] (双方向通信)▲▼[ ブラウザ (HTML5 Canvas / JavaScript) ]├── 圧力データの受信とヒートマップ描画 (30FPS)└── マウスクリック・ドラッグによるイベント送信
## 動作環境

- Go 1.16 以上
- モダンブラウザ（Chrome, Edge, Firefox, Safariなど）

## セットアップと実行方法

### 1. リポジトリのクローンまたはファイルの配置
任意のディレクトリに `main.go` と `index.html` を配置します。

### 2. 依存パッケージのインストール
WebSocketを扱うための公式サブツリーパッケージを取得します。

```bash
go get golang.org/x/net/websocket
3. アプリケーションの起動以下のコマンドでGoサーバーを起動します。Bashgo run main.go
起動に成功すると、コンソールに以下のように表示されます。Plaintextサーバー起動: http://localhost:8080
4. ブラウザでアクセスブラウザを開き、次のURLにアクセスしてください。http://localhost:8080使い方観測: 画面中央から初期の圧力が周囲に向かってじわーっと広がっていく（拡散する）様子がグラデーションで描画されます。注入: キャンバス内をクリック、またはクリックしたままドラッグすると、その場所に新たな圧力をリアルタイムで注入できます。減衰: 注入された圧力は、時間の経過とともに周囲に広がりながら徐々に消滅（エネルギー減衰）します。シミュレーションの数理について各マス（セル）の次の時間ステップの圧力 $P_{new}$ は、現在の自身の圧力 $P$ と、上下左右の隣接するマスの圧力の平均差分（ラプラシアン）から簡易的な拡散方程式を用いて計算しています。$$P_{new} = P + D \times (P_{left} + P_{right} + P_{up} + P_{down} - 4P)$$※ 本プロジェクトのコードでは、計算の安定性を考慮して拡散係数 $D$ を 0.2 に設定し、エネルギーの無限増殖を防ぐためにステップごとに 0.99 の減衰率を乗算しています。ライセンスMIT License
